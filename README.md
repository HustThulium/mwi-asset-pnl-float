# 银河奶牛放置：盈亏浮窗

需要先安装并启用 [MWITools](https://greasyfork.org/zh-CN/scripts/494467-mwitools) 的资产历史 / 盈亏功能。

安装 Tampermonkey 后，点击 [安装盈亏浮窗](https://raw.githubusercontent.com/HustThulium/mwi-asset-pnl-float/main/asset-pnl-float.user.js)。问题反馈请使用 [Issues](https://github.com/HustThulium/mwi-asset-pnl-float/issues)。

将 `asset-pnl-float.user.js` 导入 Tampermonkey，刷新游戏页面。首次安装默认不开启浮窗，只在原盈亏面板添加“弹出浮窗”按钮；点击后才启用浮窗和同步逻辑。开启 / 关闭状态会记忆：刷新后等待 MWITools 面板及六张卡片就绪，再自动恢复上次开启状态；手动关闭后刷新保持关闭。其他页签导致的临时让出不会改变开启记忆。布局设置仍会保留。已完成本地模拟测试，并根据实际游戏中的使用反馈调整交互与显示；测试范围见下文。

关闭状态不运行同步定时器、不注册页签拦截监听，也不重复写入按钮属性。仅监听节点重建以补充一次入口按钮。更新旧脚本后需刷新游戏页面，让旧版已注册的监听和定时器退出。

点击浮窗标题栏的“关闭”，关闭浮窗并清除本插件的显示覆盖，恢复正常 MWITools 盈亏页。如果正在查看公会、规划等其他页签，则保留当前页。关闭后可再次从盈亏面板点击“弹出浮窗”开启。

浮窗开启期间隐藏原“盈亏”页签，进入其他页签暂时让出时也保持隐藏；关闭浮窗后恢复。只改变显示，不移除页签节点，保留 MWITools 的挂载关系和内部激活入口。

脚本通过点击原盈亏页签使其激活，恢复原生内容的视觉显示，并解除原插件对原生页签高亮的样式覆盖。原面板保持在原 DOM 位置，以避免前置插件重建它。没有读取 MWITools 私有存储或更改其脚本；沿用原插件的数据更新频率。切换右侧页签后会尝试重新激活，可能有最长约半秒的显示延迟。

模式按钮依次切换六格、单项、完整页面。三种模式均直接定位同一个原面板到浮窗区域，不复制卡片，也不将原面板放到屏幕外。六格模式只显示摘要，单项模式只显示选中的原卡片；完整模式显示原面板全部内容，保留图表、时间范围、资产中心和数据管理按钮的交互。数字由 MWITools 直接更新；定时检查仅维持页签激活和显示状态。

进入公会、规划、收益等独占右侧内容的 MWITools 页签时，浮窗让出控制，不再重新激活盈亏。三种模式均暂时收起原面板，并在浮窗中提示正在查看的页签、更新暂停和恢复条件。返回库存等页签后自动恢复。该兼容处理不保证其他 MWITools 页签使用期间持续刷新。

标题栏拖动；右下角缩放；单项模式单击内容循环切换。位置、三种模式各自的尺寸、当前分项会保存。窗口采用固定深色背景，完整页内的卡片及图表仍采用原插件背景样式。

模式和关闭按钮使用图标，悬停提示说明操作。六格 / 单项模式鼠标离开且没有键盘焦点时，标题栏、底部控件、边框、缩放角和窗口背景自动隐藏，只保留原数据卡片；移入后恢复，拖动 / 缩放期间保持显示。完整模式始终保留框架。

六格 / 单项的圆角卡片默认使用不透明深色背景，可用底部半透明圆形图标旁的滑块调整为 20%～100% 不透明度，设置会记忆。向右更实，向左更透；悬停可查看说明。只改变卡片背景，文字保持清晰；框架隐藏前后卡片透明度一致。完整模式保留原页面背景，不显示该滑块。

单项模式的齿轮按钮可选择参与循环的六个项目，至少保留一项，循环顺序沿用原六项顺序。可关闭默认开启的“单击卡片切换”；底部左右箭头始终可手动循环翻动，旁边的 A/B 表示当前项在所选项目中的位置与总数。选择及单击开关均会记忆，不影响六格和完整模式。

## 验证步骤

1. 安装后进入盈亏面板，点击“弹出浮窗”，检查六格、单项、完整模式，以及战斗区域和右侧库存是否可操作。
2. 切换库存、装备、技能等右侧页签，检查内容及高亮是否正常，有无闪烁或卡顿。
3. 在正常游戏过程中等待资产变化，比较浮窗与打开盈亏页时的数字。仅见到“原页签已激活”不能证明数据已刷新。
4. 使用布局按钮进入完整模式，检查原图表、范围按钮等能否操作；切换角色、调整浏览器尺寸，检查是否重新挂载且没有混用角色数据。
5. 点击“关闭”，确认恢复原盈亏页行为；再次开启，并在规划页中关闭，确认仍停留在规划页。禁用脚本并刷新可完全撤销页面调整。

若切页后卡顿、原内容隐藏或数字停住，先关闭浮窗。此方案依赖 MWITools 当前的 DOM 和页签实现，前置升级后可能需要调整。

## 开发与测试

脚本使用原生 JavaScript，无构建步骤。`tests/verify.cjs` 使用 Edge 无头浏览器和模拟的前置 DOM 验证默认关闭、主动开启、关闭恢复、再次开启、导航高亮、其他页签让出、原面板交互及更新同步；不连接真实游戏，也不等同于真实 MWITools 集成验证。`tests/verify-mwitools-transition.cjs` 是前置插件页签事件顺序的最小复现，不加载本插件，不是完整的 MWITools 测试。

安装 Node.js 和 Microsoft Edge 后，在仓库目录执行：

```sh
npm install
npm run check
npm test
```

Playwright 仅用于开发测试，安装用户脚本不需要这些依赖。测试不连接用户正在使用的浏览器，也不读取游戏账号数据。

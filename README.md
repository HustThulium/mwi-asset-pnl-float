# 银河奶牛放置：盈亏浮窗

独立的 Tampermonkey 用户脚本，需先安装并启用 [MWITools](https://greasyfork.org/zh-CN/scripts/494467-mwitools) 的资产历史 / 盈亏功能。将盈亏面板显示为可拖动、缩放的浮窗，支持六格、单项和完整页面三种模式，方便在游戏过程中查看资产变化。

## 使用

- 打开 MWITools 的“盈亏”页签，点击“弹出浮窗”。首次安装默认关闭，开启 / 关闭状态会记忆，刷新后自动恢复。
- 拖动标题栏移动窗口，拖动右下角调整大小。三种模式分别记住尺寸，切换布局时保持右上角位置，方便连续操作。
- 点击标题栏的布局图标，依次切换六格、单项和完整页面。完整模式保留原面板的图表、时间范围和资产中心等功能。
- 单项模式下，单击卡片或使用底部左右箭头循环切换项目，A/B 表示当前项的位置与总数。齿轮按钮可选择参与循环的项目，并设置是否启用单击切换，至少保留一项。
- 六格 / 单项模式下，鼠标移出后自动隐藏窗口框架和控件，移入后恢复。左下角滑块可调整卡片背景透明度，文字保持清晰。
- 浮窗开启时隐藏原“盈亏”页签；点击关闭图标后恢复正常面板，可再次点击“弹出浮窗”开启。

## 安装

安装 Tampermonkey 和 MWITools 后，打开 [直接安装链接](https://raw.githubusercontent.com/HustThulium/mwi-asset-pnl-float/main/asset-pnl-float.user.js)，在扩展安装页确认。若浏览器只显示源码，可使用以下手动安装方式。

1. 在浏览器中安装 Tampermonkey，并安装、启用 MWITools。
2. 新建用户脚本，将 `asset-pnl-float.user.js` 的全部内容粘贴进去并保存。
3. 刷新游戏，确认 MWITools 的资产历史 / 盈亏功能已启用，进入“盈亏”页签并点击“弹出浮窗”。

## 当前限制

- 适用范围包含国际服、中文站及对应测试服的游戏页面；各站点与浏览器尚未逐一验证。
- 数据由 MWITools 更新，浮窗沿用其更新频率。进入公会、规划、收益等 MWITools 页签时，浮窗会显示暂停提示；返回库存等页签后自动恢复。
- 依赖 MWITools 的面板和页签结构，前置插件升级后可能需要适配。切换页签时可能有短暂显示延迟。
- 当前版本已在游戏内试用。若出现切页异常或数据停住，可先关闭浮窗；禁用脚本并刷新游戏可撤销页面调整。安装或更新脚本后也需刷新游戏。

## 开发

本项目为独立插件仓库，使用原生 JavaScript，无构建步骤。可用 Node.js 检查语法：

```sh
node --check asset-pnl-float.user.js
```

本地模拟测试位于 `tests/`，安装开发依赖后可执行 `npm test`，需要 Microsoft Edge。安装用户脚本无需这些依赖。

此项目为玩家个人开发，与游戏及 MWITools 没有官方关联。浮窗复用 MWITools 原面板，不修改其脚本；浮窗设置保存在浏览器本地。问题反馈请使用 [Issues](https://github.com/HustThulium/mwi-asset-pnl-float/issues)。
